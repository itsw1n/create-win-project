# DevOps: Pull Request Template

## Template

GitHub loads `.github/PULL_REQUEST_TEMPLATE.md` when a contributor opens a pull request. Complete
its Summary, Validation, and relevant Notes before opening the PR. Remove the Notes section when
there are no risks, screenshots, migrations, or follow-up items to report.

Report only commands and checks that actually ran. Do not mark a checklist item complete when a
required check failed; state the exact blocker instead. Never open a pull request unless the user
explicitly authorizes it.
